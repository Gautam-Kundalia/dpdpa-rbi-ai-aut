DPDP Regulatory Change Monitor

How the daily pipeline works

One automated run, once a day: three government sources are checked for changes, one AI agent decides whether a change is real, and every step writes to a single audit trail.

1 AI agent· 3 external sources· 3 database tables· runs daily, scheduled 06:17 IST (00:47 UTC); GitHub may still start it hours late

No human review gate today. Every change the AI agent reports is written straight into the live database and the published documents. The agent's own confidence score is recorded for the audit trail, but nothing currently blocks on it.
