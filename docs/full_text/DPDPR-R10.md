**Rule 10 — Verifiable consent for processing of personal data of child**

(1) A Data Fiduciary shall adopt appropriate technical/organisational measures to obtain verifiable parental consent before processing a child's personal data, with due diligence to check the self-identified parent is an identifiable adult, by reference to: (a) reliable identity/age details already held; or (b) details voluntarily provided by the individual or via a virtual token issued by an authorised entity (which can include a Digital Locker Service Provider).

(2) Defines 'adult' (18+), 'authorised entity', and 'Digital Locker service provider'.

The Rules include four worked case illustrations covering combinations of whether the declared parent is already a registered user of the platform and how identity/age is verified — see full Gazette text for exact wording.
